Tetris Game Documentation

Overview

This project implements a classic Tetris game using C and the NCurses library. The game allows players to control falling tetrominoes, clearing lines and scoring points. The project includes functionality for game initialization, user input handling, collision detection, and score management.

Features

  • Classic Tetris gameplay
  • Various tetromino shapes
  • High score tracking
  • User controls for piece movement and rotation
  • Line clearing and score management

Installation

Prerequisites

  • GCC (GNU Compiler Collection)
  • NCurses library
  • Check library (for unit testing)
  • Make

Steps

1. Install the NCurses, GCC compiler, Make and Check libraries (if not already installed):

2. Compile the game using makefile (src folder):
   make install

Usage

Run the game using the following command:

./build/tetris

Game Controls

  • Arrow Left: Move piece left
  • Arrow Right: Move piece right
  • Arrow Down: Drop piece
  • Space: Rotate piece
  • P: Pause/Resume the game
  • Q: Quit the game

Function Descriptions

void init_game()

Initializes the game state, including the game field and the first tetromino pieces.

void userInput(UserAction_t action, bool hold)

Handles user input to control the game actions based on the specified action.

GameInfo_t updateCurrentState()

Updates the current game state, including moving the tetromino down automatically based on the game speed.

void create_new_falling(Game* game)

Generates a new tetromino piece and checks for game over conditions.

int check_block_fits(const Game *game, Tetromino *block)

Checks if the current piece collides with the game field or boundaries.

void fill_next_func(GameInfo_t *game_info, Tetromino *next)

Fills the next tetromino piece to be displayed on the game interface, updating the game information structure accordingly.

Game *get_current_game_info()

Retrieves the current game information, including the state of the game field and the active tetromino.

GameInfo_t init_game_info()

Initializes the game information structure, setting up the initial state of the game, including score, level, and the next tetromino.

void check_lines_full(Game *game)

Checks for any completed lines in the game field and removes them, updating the score and potentially increasing the game speed.

void process_rotation(Game *game)

Handles the rotation of the current tetromino piece, ensuring that it fits within the game boundaries and does not collide with other pieces.

void move_right_or_left(Game *game, int direction)

Moves the current tetromino piece to the right or left based on the specified direction, checking for collisions with the game field boundaries.

void move_block_down(Game *game)

Moves the current tetromino piece down by one row in the game field, checking for collisions and handling any necessary game state updates.

void fill_current_from_next(Game *game)

Transfers the next tetromino piece into the current active piece, preparing for the next move in the game.

int **create_matrix(int rows, int columns)

Creates a 2D matrix of integers with the specified number of rows and columns, initializing all elements to zero.

void put_block(Game *game, Tetromino *block)

Places the specified tetromino block onto the game field, updating the game state to reflect the new position of the block.

void remove_block(Game *game, Tetromino *block)

Removes the specified tetromino block from the game field, allowing for the movement of other pieces.

void state_machine(Game *game)

Implements the game state machine, managing transitions between different game states such as playing, paused, and game over.

void move_figure(Game *game)

Handles the movement of the current tetromino piece based on user input and game logic, including automatic downward movement.

void finish_game(Game *game)

Finalizes the game state, performing any necessary cleanup and displaying the final score or game over message to the player.

void move_to_bottom(Game *game)

Moves the current tetromino piece down to the lowest possible position in the game field, either until it collides with another piece or reaches the bottom.

void process_input(int c)

Processes user input from the keyboard, translating key presses into game actions such as moving or rotating the tetromino.

int timer(Game *gs, int delay)

Implements a timer function that manages the game speed, triggering updates to the game state at specified intervals.

void free_matrix(int **matrix, int rows)

Frees the memory allocated for a 2D matrix of integers, ensuring proper memory management and preventing memory leaks.

long long get_time()

Retrieves the current time in milliseconds, which can be used for timing events or measuring game duration.

Tetromino *rotate_block(const Tetromino *block, TetrominoMap *blocks, int shift)

Rotates the specified tetromino block based on the shift parameter, which determines the direction of rotation (3 for right, 1 for left).

void init_new_map_block(TetrominoMap *blocks, int type)

Initializes a new block in the tetromino map based on the specified type, setting up its shape and rotation states.

TetrominoMap *init_all_block_types()

Initializes all types of tetromino blocks, preparing them for use in the game by setting their shapes and rotation states.

void init_new_block(TetrominoMap *blocks, int type, Game *game)

Initializes a new tetromino block of the specified type, updating the game state to reflect the new block and its position in the game field.

void init_block_I(TetrominoMap *tetris)

Initializes the I-shaped tetromino block, defining its rotation states and shape for use in the game.

void init_block_L(TetrominoMap *tetris)

Initializes the L-shaped tetromino block, setting up its rotation states and shape for gameplay.

void init_block_J(TetrominoMap *tetris)

Initializes the J-shaped tetromino block, defining its rotation states and shape for use in the game.

void init_block_O(TetrominoMap *tetris)

Initializes the O-shaped tetromino block, setting its fixed shape since it does not rotate.

void init_block_S(TetrominoMap *tetris)

Initializes the S-shaped tetromino block, defining its rotation states and shape for gameplay.

void init_block_T(TetrominoMap *tetris)

Initializes the T-shaped tetromino block, setting up its rotation states and shape for use in the game.

void init_block_Z(TetrominoMap *tetris)

Initializes the Z-shaped tetromino block, defining its rotation states and shape for gameplay.

void fill_block_matrix(TetrominoMap *tetris, position states[4][4])

Fills the block matrix for a given tetromino type with its rotation states, allowing for proper rendering and collision detection during gameplay.
