# Snake (Змейка)

Краткая документация по модулю `snake` в проекте BrickGame.

## Структура

- `controller/` — обработка ввода и связь между UI и моделью.
  - `controller.cc`, `controller.h` — логика управления игрой из CLI/desktop.
- `model/` — вся игровая логика и модель змейки.
  - `game.cc`, `game.h` — основной цикл игры, состояние, счёт, фрукты.
  - `snake.cc`, `snake.h` — модель тела змейки, движение, коллизии.
- `README.md` — этот файл.

## Короткая архитектура

Модель (model) отвечает за внутреннее состояние: поле, положение змейки, спавн фрукта, счёт и уровни.
Контроллер принимает пользовательский ввод (стрелки, пауза, рестарт) и вызывает соответствующие методы модели.
Фронтенд (CLI/GUI) рендерит `game_info_.field`, используя цвета/символы для головы, тела и фрукта.

Основные классы/структуры:
- `Game` — хранилище состояния игры, управление состояниями (MOVING, SPAWNING, EATING, GAME_LOST), обработка таймеров и входа.
- `Snake` — структура тела змейки, методы `Move()`, `AddPart()`, `SetDirection()` и проверка коллизий.
- `Position` — простая структура {x,y} для координат.

## Сборка и запуск

Перейдите в каталог `src/` и выполните:

```bash
make install
# или только консольную версию змейки
make snake
# затем запустить
./build/snake_console
```

> Примечание: Makefile использует `g++` для сборки C++ модулей и `gcc` для C.

## Тестирование

Юнит-тесты для змейки лежат в `tests/snake_tests/`.
Чтобы запустить их, из `src/` выполните:

```bash
make test
```

Это создаст бинарник `build/snake_unit_test` и выполнит его (требуются GoogleTest и связанные библиотеки).

## Контролы

- Стрелки — движение
- P — пауза/возобновление
- Q / Terminate action — выход
- Start action (обычно Enter) — рестарт после проигрыша

## Замечания для разработчика

- Сохранение рекорда происходит в `snake_high_score.txt` в рабочем каталоге.
- Поле создаётся динамически в `Game::InitGame()`; при добавлении новых размеров убедитесь, что память корректно освобождается в деструкторе.
